# 4. Policies and Procedures

**Status: outline, full content in progress**

## What this section will cover

- The full set of policies most SOC 2 audits expect to see, and which ones are commonly missing in first-time programs
- How to write policies that describe what your company actually does, rather than copying a template and hoping practice catches up
- Getting policy approval and version control right so you can prove a policy was in effect during the audit window
- Employee acknowledgement tracking, since an unread policy is treated by auditors as a policy that does not exist
- The minimum policy set for a first Type I audit versus the fuller set expected by Type II
- Life sciences note: aligning SOC 2 policies with existing SOPs so Quality and IT are not maintaining two separate and possibly conflicting documents on the same topic
