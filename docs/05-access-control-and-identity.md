# 5. Access Control and Identity

**Status: outline, full content in progress**

## What this section will cover

- Building a joiner, mover, leaver process that produces auditable evidence automatically
- Least privilege and role-based access as applied to production systems, source code, cloud infrastructure, and business applications
- Access review cadence: what auditors expect to see (typically quarterly) and how to run reviews that are not rubber stamps
- MFA, SSO, and privileged access management expectations for a Type II audit
- Offboarding timing and why same-day revocation is the standard auditors test against
- Life sciences note: reconciling SOC 2 access control evidence with 21 CFR Part 11 audit trail and electronic signature requirements so the same access review can satisfy both

## Common mistakes this section will address

- Access reviews that are performed but not documented, which is functionally the same as not performing them in an audit
- No formal process for contractor and temporary access, which auditors specifically probe for
