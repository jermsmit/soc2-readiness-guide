# 3. Running the Gap Assessment

**Status: outline, full content in progress**

## What this section will cover

- Structuring a gap assessment against the Common Criteria before you write a single policy
- Building a control matrix: control description, owner, current state, target state, evidence source
- Interviewing engineering, HR, and IT leads to find undocumented practices that already satisfy a control versus practices that need to be built from scratch
- Prioritizing remediation by audit risk and implementation effort, not by what is easiest to fix first
- Setting a remediation timeline that accounts for the Type II observation window
- Life sciences note: cross-referencing SOC 2 gaps against existing GxP or validated system controls so you are not rebuilding something Quality already owns

## Common mistakes this section will address

- Running the gap assessment as a paperwork exercise instead of interviewing the people who actually do the work
- Underestimating how long access control and vendor management remediation takes relative to other domains
